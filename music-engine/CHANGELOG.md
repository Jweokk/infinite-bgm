# 变更记录

## v1.1.0（2026-10-02）· 中英双语 · 日夜模式 · 访问计数

### 1. 中英双语界面（右上角 `EN` / `中` 切换）
- **全部界面文案**双语：标题、按钮、状态、参数面板、提示（toast）、帮助弹层全文。
- **风格元数据**双语：16 个风格的描述、全部参数字段名（如「空间 / Space」「聆听目的 / Purpose」）、
  下拉选项（音阶、睡眠时长、聆听目的）与预设名；风格 **id / 参数 id / 预设 id 一律不变**，
  音乐生成逻辑与种子复现完全不受影响。
- 语言解析顺序：`?lang=en|zh` → 上次选择（`localStorage`）→ 浏览器语言（中文浏览器用中文，
  其它默认英文）。切换即时生效，无需刷新；同时更新 `<html lang>` 与页面标题。
- 实现方式：`src/i18n/`（`ui.ts` 界面字典 + `meta.ts` 风格元数据字典 + `index.ts` 解析/本地化）；
  EN 字典以 `Record<keyof typeof ZH, string>` 强类型约束，**漏译即编译失败**；测试会遍历 16 个风格插件
  的全部中文字段，缺一条即报错。

### 2. 日夜模式（右上角 ☾ / ☀ 切换）
- 新增完整**亮色主题**：所有硬编码颜色收敛为 CSS 变量（`--card/--field/--track/--stage/--viz-*` 等），
  `[data-theme='light']` 统一定义亮色值；**暗色渲染与 v1.0.x 逐像素一致**。
- 解析顺序：`?theme=light|dark` → 上次选择 → 系统 `prefers-color-scheme`（并监听系统切换，直到用户显式选择）；
  首屏在 `main.ts` 挂载前落 `data-theme`，避免亮色用户看到暗色闪屏。
- 可视化画布、`<meta name="theme-color">`、原生控件（`color-scheme`）随主题同步。

### 3. 访问计数 + IP 来源统计（页脚 👁）
- 页脚显示「访问 N 次 · 访客 M 人」，数据来自可选后端 `counter/`（**纯 Python 标准库，零依赖**）。
- 统计内容：每次页面访问记录 **IP、国家/地区、城市、ASN（Cloudflare 头部）、UA、来源页、
  语言/主题、屏幕、时区、时间**；聚合出总访问、独立访客（salted IP hash）、按日访问、
  国家/城市/ASN 排行。
- 报表页 `/stats?token=<BGM_STATS_TOKEN>`（令牌在服务器 `.env`，不进仓库）。
- **站点本身仍是纯静态**：计数器服务未部署或挂掉时，页脚自动隐藏计数，播放完全不受影响。

### 4. 内部改进
- **引擎错误码化**：核心不再内嵌 UI 文案，改为发 `code` + 参数（如 `audioUnlockFailed`、
  `styleFallback{ saved, name }`），由 UI 按当前语言渲染 —— 这是双语能覆盖错误提示的前提。
- 无头测试从 161 增至 **175**（新增 `tests/core/I18n.test.ts`：字典键对齐、EN 无中文残留、
  16 风格元数据全覆盖、本地化不破坏 id、语言/主题解析优先级）。
