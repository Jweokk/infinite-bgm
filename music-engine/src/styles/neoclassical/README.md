# Neo-Classical Plugin

Slow-beat neo-classical piano.

- Time Model: `beat` (52–84 BPM) · Instruments: felt-piano / drone
- Broken-chord figures (Alberti/arpeggio) with voice-led voicings
- Long cantabile melodies; soft strings pad (root+fifth drone) underneath
- Felt piano: darker EP partials + mechanical felt thump on the attack
