# Dark Ambient Plugin

Free-time dark ambient — the tension pole.

- Time Model: `free` · Instruments: drone / bell / noise-texture
- Sub-register pedal (D0–A0) + dissonant color voices (tritone / m9 / m2)
- Rare far-away metal hits, barely-there dark room tone
- Very long reverb, dark EQ; `dread` scales the unease
