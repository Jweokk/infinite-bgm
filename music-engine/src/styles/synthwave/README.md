# Synthwave Plugin

Beat-based retro synthwave (i–VI–III–VII progressions).

- Time Model: `beat` · Instruments: supersaw / pluck / kick / snare / hat
- Supersaw chord pads (6-osc detuned saw stack), 16th analog arpeggios
- Gated drums (4-floor at high energy), strong sidechain pump
- Heavy reverb + delay + saturation; tape wobble for the VHS sag
