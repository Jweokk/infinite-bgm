# Ambient Plugin

Evolving chord clouds.

- Time Model: `free` · Instruments: drone / pluck / noise-texture
- Every 28–75s a chord stack (root, 5th, 9th, color 3rd) crossfades into the next
- Cloud root drifts by ±1/2/5 semitones; plucks follow the cloud root
- Heavy reverb + shimmer; no drums, no bells
