# Minimal Plugin

Glass/Reich-flavoured pattern music.

- Time Model: `beat` · Instruments: pluck / electric-piano (+ kick)
- Repeating arpeggio contours over 4-bar chord spans (8ths or 16ths)
- Phase motion rotates the contour start every few bars; long melody tone every 8 bars
- Optional soft four-on-the-floor; defaults to the `focus` purpose
