# Meditation Plugin

Breath-driven meditation generator (PRD §77–93).

- Time Model: `breath` · Instruments: drone / bowl / bell (+ pluck, noise-texture)
- Bells soft-locked to inhale peaks (alignProb 0.45 + breathRate·0.4)
- Warm low drone, single-note harmonic-field morphing, transitionSpeed stretches field spans
- Defaults to the `meditation` purpose profile
