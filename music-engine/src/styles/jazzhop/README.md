# Jazzhop Plugin

Beat-based jazz-hop generator.

- Time Model: `beat` · Instruments: electric-piano / bass / hat / kick / snare (+ pluck)
- Walking bass: quarter notes through chord tones with chromatic approach into the next root
- Ride kit: swung ride pattern (1, 2, 2&, 3, 4, 4&), hi-hat foot on 2 & 4, feathered kick, ghost snare
- Rootless jazz voicings + swung melodies (reuses the lofi generators, configured jazzier)
- Same seed + config → identical events; chunking-invariant lanes.
